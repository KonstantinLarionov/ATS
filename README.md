# Agent Task Studio (ATS)

Продающий лендинг [Agent Task Studio](https://github.com/KonstantinLarionov/ATS) — локальной студии управления задачами и AI-агентами.

## Что здесь

- `index.html` — одностраничный лендинг (без сборки и зависимостей)
- `assets/icon.png` — логотип приложения
- `assets/app-mobile.png` — скриншот мобильного приложения

## Публикация

Достаточно залить файлы в репозиторий — лендинг статический, никакой сборки не требуется. Для GitHub Pages включите Pages с веткой `main` и корнем `/`.
